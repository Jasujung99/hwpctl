# 공개 릴리스 체크리스트

이 문서는 릴리스 담당자가 직접 확인할 게이트입니다. 체크 자체가 태그나 배포를 실행하지
않습니다. 테스트에는 개인정보 없는 빈 문서와 복사본만 사용합니다.

## 공개 위생

- [ ] 작업 트리에 의도하지 않은 파일이 없다.
- [ ] 실제 HWP/HWPX, 프로필, 토큰, 인증서, 로컬 MCP 설정, 사용자 경로와 스크린샷이
      추적되지 않는다.
- [ ] README 예제와 MCP 도구 목록이 현재 CLI와 일치한다.
- [ ] [알려진 한계](../KNOWN_LIMITATIONS.md), [보안 정책](../SECURITY.md),
      [제3자 고지](../THIRD_PARTY_NOTICES.md)를 검토했다.
- [ ] GitHub Private Vulnerability Reporting과 `main` 보호 규칙이 활성화되어 있다.

## 자동 검사

- [ ] MCP 1.x 전용 가상환경에서 전체 `pytest`가 통과한다.
- [ ] wheel과 sdist가 빌드되고 설치 가능한지 확인했다.
- [ ] `hwpctl mcp --list-tools`가 한글 없이 성공한다.
- [ ] 모든 JSON/TOML 클라이언트 예제가 파싱된다.

## Windows + 한글 2022 실기

테스트 기록에 Windows·한글 빌드, Python, `pyhwpx`, MCP 클라이언트 버전을 남긴다.

- [ ] 한 창에서 `status`와 `snapshot`이 대상 제목·경로·본문을 정확히 읽는다.
- [ ] 여러 한글 창이 있을 때 고정 대상이 유지되거나 안전하게 거부된다.
- [ ] 짧은 본문·제목 입력과 글꼴·크기·색·정렬이 화면에 즉시 반영된다.
- [ ] 표 생성·채우기, 셀 여백·너비·높이·병합·세로정렬·테두리와 `layout_review`를
      확인한다.
- [ ] 쪽 이동·나누기·용지 설정과 스타일 적용을 확인한다.
- [ ] 차트 종류와 데이터 대화상자 억제를 확인하고 추론값 결과를 기록한다.
- [ ] 각 명령 뒤 Undo 횟수를 측정하고, 명령 사이 수동 편집 시 한계를 확인한다.
- [ ] `save_as`가 원본을 보존하며 같은 경로와 무단 `save`가 거부된다.
- [ ] 보안 모듈·보호 문서·한글 대화상자가 뜰 때 자동으로 진행하지 않고 안전하게
      중단한다.
- [ ] 줄 간격 직접 변경은 현재 미지원임을 확인하고 호환성 표에 기록한다.

## 릴리스

- [ ] 모든 게이트 통과 후에만 `v0.1.0` 태그와 GitHub Release를 만든다.
- [ ] 이번 단계에서는 PyPI에 배포하지 않는다.
